Bash Scripting

Что такое Bash?

Bash — это мощный инструмент для работы с операционной системой.
Он позволяет автоматизировать рутинные задачи, управлять файловой системой,
обрабатывать текст и создавать сложные скрипты для администрирования серверов. Будучи интерпретируемым языком, Bash выполняет команды последовательно, шаг за шагом.

Скрипты (Shebang)

Любой bash-скрипт должен начинаться со специальной первой строки — шебанга: #!/bin/bash. Эта директива сообщает ядру операционной системы, что файл нужно выполнять именно с помощью интерпретатора Bash.

Переменные

В Bash строгая типизация отсутствует. Чтобы создать переменную, достаточно присвоить ей значение без пробелов вокруг знака равенства: USER="Alex". Для обращения к значению переменной используется знак доллара: echo $USER.

Условия

Для создания логических ветвлений применяются конструкции if, then, elif, else. Блок условия обязательно закрывается словом fi (if наоборот). Например: if [ "$A" -eq 1 ]; then echo "Yes"; fi.

Циклы

Для многократного выполнения кода доступны циклы for, while и until. Они отлично подходят для перебора списка файлов в директории, построчного чтения документов или обработки массивов данных.

Функции

Повторяющиеся фрагменты кода можно оборачивать в функции. Функция объявляется словом function my_func() { ... }. Аргументы внутрь функции передаются не в скобках, а вызываются внутри как $1, $2 и т.д.

Конвейеры (Pipes)

Одна из главных особенностей Unix-систем — возможность передавать результат работы одной программы на вход другой. Это делается символом вертикальной черты |. Пример: ls -l | grep ".txt" найдет все текстовые файлы.
